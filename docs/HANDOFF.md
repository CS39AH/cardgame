Known issues:
  1. Balancing cards and zones. Some zones are hard than expected while others are easier than expected.
  2. Card size. Card details for some of the long winded cards are sometimes hard to read so upsizing the zoom in on cards could be good.
  3. Playing on some devices makes the format of the UI look wrong.
  4. Performance issues causing the game to take a bit to load.

Moving Forward:
  1. Rebalance cards to their zones.
  2. Rebalance zones so that it feels progressively harder.
  3. Rebalance hero abilities as some seem too powerful and others too weak.
  4. Resize card zoom so that cards are easier to read.
  5. Develop different UI for different devices.
  6. Optimize performance to not strain the device.
